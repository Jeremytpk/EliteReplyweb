# How to Host APK on Firebase Storage

## Step 1: Install Firebase CLI (if not already installed)
```bash
npm install -g firebase-tools
```

## Step 2: Login to Firebase
```bash
firebase login
```

## Step 3: Deploy Storage Rules
```bash
firebase deploy --only storage
```

## Step 4: Upload APK to Firebase Storage

You have two options:

### Option A: Using Firebase Console (Easiest)
1. Go to https://console.firebase.google.com/
2. Select your project: `elitereply-bd74d`
3. Click on "Storage" in the left menu
4. Click "Upload file"
5. Create a folder called `downloads`
6. Upload `assets/files/EliteReply_Android.apk` to the `downloads` folder
7. Click on the uploaded file
8. Copy the "Download URL" (it will look like: `https://firebasestorage.googleapis.com/v0/b/elitereply-bd74d.firebasestorage.app/o/downloads%2FEliteReply_Android.apk?alt=media&token=...`)

### Option B: Using Firebase CLI
```bash
# Navigate to your project
cd /Users/tpk/Documents/Jerttech/EliteReplyWeb

# Upload the APK
firebase storage:upload assets/files/EliteReply_Android.apk downloads/EliteReply_Android.apk
```

## Step 5: Update Download Links

Once you have the Firebase Storage URL, update these files:

### In `components/header.html` (line ~402):
```javascript
link.href = 'YOUR_FIREBASE_STORAGE_URL_HERE';
```

### In `index.html` (line ~274):
```javascript
link.href = 'YOUR_FIREBASE_STORAGE_URL_HERE';
```

## Step 6: Add APK to .gitignore

To prevent accidentally committing large files:

```bash
echo "assets/files/*.apk" >> .gitignore
```

## Step 7: Commit and Push Changes

```bash
git add .
git commit -m "Update storage rules and use Firebase Storage for APK hosting"
git push
```

## Expected Firebase Storage URL Format
```
https://firebasestorage.googleapis.com/v0/b/elitereply-bd74d.firebasestorage.app/o/downloads%2FEliteReply_Android.apk?alt=media&token=XXXXX
```

The token at the end is automatically generated by Firebase for security.
